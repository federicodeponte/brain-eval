08 · three rulescontext-ly

Three rules.

1

Use it, don't say it.

Private facts shape the plan. They never appear in a message.

knows 0.81 → proposes the right scope
2

Who's asking, and why.

Only what the request needs. More takes Maya's one tap.

Jun · collaborator · plan project
3

Check before speaking.

If a reply could give a secret away, rewrite it.

"before she leaves" → "this spring"
