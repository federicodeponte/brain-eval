Can a model read a brain?

We give frontier models raw spike counts from real neurons, plus a few labeled examples, and ask what the brain was seeing. A ten-line decoder with the same examples is the bar to beat.

The task

Try one yourself

Forty neurons in the amygdala and hippocampus of epilepsy patients, recorded through clinical depth electrodes while they looked at photos. Each row is how many spikes every neuron fired between 200 and 1200 ms after a photo appeared. Three labeled rows per category, then one new row. Which category is it?

The model sees this exact table, as numbers. Darker cells mean more spikes.

Data: DANDI 000004 (Rutishauser lab), CC-BY-4.0. Neurons are pooled across 12 recording sessions, so each row is a pseudo-trial. The new row's photo never appears in the examples.

First results

Opus keeps up with a classic decoder. Haiku doesn't.

Pilot run: the same 10 questions per task for every solver, one shot per question, no tools. The decoder is nearest-centroid on the labeled rows in the prompt, so it gets exactly the information the model gets.

Chance Haiku Opus Decoder

With 10 questions each bar is about ±15 points. The full run on Valkyrie uses 40 to 90 questions per task and three models.

Is it really learning?

Five checks

A high score could come from guessing, from what the model already knows about the brain, or from a leak. Each check below rules one of those out.

Swapped labels

Car photos are labeled "food" in the examples. A model that reads the neurons follows the labels; one that relies on brain trivia picks the real category. Opus followed the examples 12 of 20 times and the real category 3 of 20. The decoder: 65% and 12.5%.

Passed

Learning curve

Same questions with 0, 1, 3 or 5 examples per option. Zero examples must sit at chance; accuracy should climb with each example. With 0 examples Opus answered "A" every time, which is chance. With 1 example it got 7 of 10.

Passed

Swapped clip

The right answer's examples are replaced with a clip from another movie. The correct reply is "none of these".

Built

Shuffled spikes

Real firing rates with the structure destroyed. Anything above chance means a leak or a letter bias.

Built

Planted pattern

An obvious pattern planted in synthetic data. Should be near 100%, which checks the harness and the answer parser.

Built
Mouse task: Allen Brain Observatory Neuropixels session 732592105, 40 visual-cortex units in ten 100 ms bins, which of 4 or 8 one-second movie clips.
Harness: Valkyrie, one-call multiple-choice agent, exact-match grader that only accepts a valid letter.
Data credits: Chandravadia et al. 2020, Scientific Data, NWB dataset of human single-neuron activity (patients with drug-resistant epilepsy, depth electrodes for seizure localization). Faraut et al. 2018, Scientific Data, "Dataset of human medial temporal lobe single neuron activity during declarative memory encoding and recognition" (DANDI 000004, CC-BY-4.0). Siegle et al. 2021, Nature, "Survey of spiking in the mouse visual system reveals functional hierarchy" (Allen Brain Observatory).
